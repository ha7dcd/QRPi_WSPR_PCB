# QRPi WSPR PCB - 20 m "Whispering Raspberries"

20 m band, 20 dBm WSPR transmitter add-on board for the Raspberry Pi (rev 1.6).

## Contents

- `Eagle/20m_QRPi_1V6.sch`, `Eagle/20m_QRPi_1V6.brd` - EAGLE schematic and board (EAGLE 6.4 XML)
- `Eagle/20m_QRPi_1V6_sch.pdf`, `_top.pdf`, `_bot.pdf` - schematic and board prints
- `Eagle/20m_RPI_WSPR_TX_BOM_SMDmount.xlsx` - bill of materials (SMD assembly)
- `Eagle/CAM/20m_RPI_WSPR_TX_1v6.zip` - manufacturing files: Gerbers, Excellon drill, PDFs
